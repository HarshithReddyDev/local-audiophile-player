# Troubleshooting

- **Won't start** — read the banner (missing file vs codec); press play
  once (autoplay policy); reconnect cloud sources.
- **Too quiet** — volume/mute/OS level, then preamp, ReplayGain mode,
  compressor makeup.
- **Clips** — apply suggested preamp, reduce boosts, keep the limiter on.
- **EQ inactive** — EQ enabled? DSP bypassed/comparing? Right device
  profile? Right EQ mode (parametric vs graphic)?
- **Background stopped** — the app never pauses on hide; the OS suspended
  it or a cloud URL expired. Return and press play.
- **Media Session / output unavailable** — platform support varies;
  in-app transport always works; device selection is Chromium-only.
