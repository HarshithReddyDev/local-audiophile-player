# Player

- **Now Playing** — large artwork, title/artist/album, progress,
  transport, favorite, queue, device + EQ/DSP status, lyrics, visualizer,
  track info.
- **Mini player** — artwork, track, artist, play/pause, progress; tap to
  open Now Playing.
- **Queue / shuffle / repeat** — repeat-one affects natural endings only;
  manual Next always advances.
- **Crossfade** — 0.5–12 s equal-power blends via the standby deck.
- **Rate** — 0.25–2× with optional pitch preservation.
- **Background** — audio continues across tabs/minimize; lock-screen
  controls use Media Session where supported.
- **Shortcuts** — Space/K play-pause, arrows seek, Ctrl+arrows change
  track, M mute, Q queue, E EQ & DSP, Ctrl/⌘+K palette.
