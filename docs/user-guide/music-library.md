# Music Library

One **Music** workspace with a search box and six tabs: All, Albums,
Artists, Genres, Recently Played, Favorites.

- **All** — Recently Played, Recently Added, Favorites, Albums, All Music.
- **Albums** — cards with hover/tap play; open a card for the track list.
- **Artists / Genres** — grouped browsing with detail views.
- Track rows show artwork, title, artist, album, duration; hover reveals
  play and favorite actions (always visible on touch devices).

Files stay local. Metadata comes from tags with filename fallback.
