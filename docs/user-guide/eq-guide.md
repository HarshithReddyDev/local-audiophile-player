# EQ Guide

EQ applies frequency-dependent gain. Practical landmarks (not absolute
categories): 20–60 Hz sub-bass, 60–250 bass, 250–500 lower mids,
500 Hz–2 kHz midrange, 2–6 kHz presence, 6–12 kHz treble, 12 kHz+ air.

- **Gain** — + boosts, − cuts, 0 unchanged. Prefer cuts; they cost no
  headroom.
- **Q** — low Q is broad/musical, high Q narrow/surgical.
- **Peak** — frequency + gain + Q. The workhorse.
- **Shelves** — broad bass/treble tilts around a turnover frequency.
- **Graphic EQ** — fixed bands, slider per band (constant-Q here).
- **Preamp** — offset the largest boost (≈ −5 dB for +5 dB peak) to avoid
  clipping past 0 dBFS. The EQ screen suggests a value; one tap applies it.
  The estimate is a static safety margin, not true-peak metering.

To EQ an IEM: select device → load measurement → choose target → AutoEQ
→ inspect → apply preamp → listen → A/B → adjust → save. Preference is
subjective; start small, change one band at a time, A/B at matched
loudness, never chase loudness, keep levels safe.
