# AutoEQ Guide

Measurement → target → smoothing → compensation → constrained fitting →
PEQ + recommended preamp. An approximation: inspect and listen before
saving.

- Fits clamp to measured data (never extrapolated); treble fits stay
  conservative.
- **Smoothing** (Off/Light/Moderate) preprocesses a derived copy only;
  raw data is untouched. Default Off.
- Apply the generated preamp. Verify device, measurement, fit range, and
  residual error first.
